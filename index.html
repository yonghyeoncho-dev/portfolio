운영 도구를 만들어 왔습니다

7년간 만든 화면의 대부분이 운영자가 쓰는 화면이었고, 반복되는 것은 도구로 바꿔왔습니다.

01

운영자 화면 설계

ERP · 업무포털 · 전자입찰이 대부분이었습니다. 대용량 데이터 그리드, 검색 · 필터, 화면 간 데이터 흐름 정의. 운영자가 하루 종일 보는 화면이라 밀도와 조작 동선이 먼저입니다.

02

반복 패턴을 패키지로

시스템관리 · 메뉴관리 · 코드관리처럼 SI마다 처음부터 다시 만들던 공통 화면을 DevPack 표준 패키지로 묶었습니다. 신규 프로젝트는 조립에서 시작합니다.

03

수작업을 규칙으로

레거시 UI 전환의 반복 공정을 자동화 도구 5종으로 대체했습니다. 도구만 만들고 끝내지 않습니다 — 프로젝트마다 표준 가이드와 산출물을 남겨 다음 사람이 같은 시행착오를 겪지 않게 합니다.
